蓝牙密语 隐私政策

版本 10 · 生效日期 2026-11-07 · 适用于 Google Play 上的「蓝牙密语」（com.btchat.app）

蓝牙密语提供蓝牙近场通信和基于 WebRTC 的 P2P 对端会话（可选经加密中继转发）。应用会使用本机网络能力，但不依赖账号或云端聊天服务。普通消息的明文只按会话需要保存在内存，并按处置规则清除。

网络权限与本机读取

应用声明 ACCESS_NETWORK_STATE，用于在本机读取默认网络的能力、地址和变化，以判断是否具备直接 P2P 尝试条件；这只是系统只读状态查询，不发起远端请求。应用还声明 INTERNET，使 WebRTC 能通过系统 socket 与直接 P2P 对端建立连接，并在开启「远程连接增强」时连接 STUN 服务器与加密中继。这两项均为普通安装权限，不会因此弹出运行时授权框。蓝牙、定位、相机、NFC、通知、存储、前台服务、生物识别等其他权限仍按对应功能和系统版本申请。

远程邀请、IP 与 ICE 信息

签名 Offer/Answer 邀请有两种交给对方的方式：开启「远程连接增强」（默认开启）时，邀请经下文所述的加密中继投递，对方扫一次「小直连码」即可发起加好友请求（小直连码只含一次性钥匙和你的身份指纹 friendId，不含 IP 地址）；关闭时，你需要通过应用内复制、系统剪贴板粘贴或扫码等方式，主动把邀请交给对方。扫码只发起请求，双方需核对页面显示的相同安全码并分别同意后才保存好友；任一方拒绝或超时均不保存。邀请包含邀请类型、随机编号、有效时间、发送者与接收者 friendId、发送者 SPKI 公钥、临时公钥、签名，以及 SDP/ICE host 候选；开启增强时还包含经 STUN 查询得到的公网地址候选。SDP/ICE host 候选可能包含设备 IP 地址、端口和协议等连接信息；直接 P2P 对端在连接过程中也会获得建立连接所需的对端网络信息。你复制到剪贴板或交给其他渠道后，能看到该邀请的人也可能读到这些信息，请只发给你信任的对端，并在邀请过期后勿再使用。

外部渠道由你选择

复制、粘贴、导出或分享邀请、诊断信息和其他内容时，外部渠道完全由你自行选择；本应用不调用这些渠道的 API，不自动发送，也不能控制你已经交给外部应用或接收者的副本。系统剪贴板可能按系统规则被其他应用或历史记录功能读取，请在使用后及时清理。

语音与视频通话

通话只能在已连接、端到端加密且已验证的单聊中由你本人发起或接听。邀请、接听、挂断等通话信令走现有的加密聊天会话；接通后，声音与画面经 WebRTC 在两台设备之间直接传输，并以 DTLS-SRTP 加密，加密指纹随加密信令交换，中继与 STUN 服务器无法解密或冒充。通话需要双方设备能直接互通：开启「远程连接增强」时会像聊天一样向公共 STUN 服务器查询本机公网地址；本应用不使用 TURN，通话音视频不经中继转发，双方网络无法直连时通话会失败。直接通话时对方设备会获得你的 IP 地址与端口。麦克风只在通话进行中录音，摄像头只在视频通话且你未关闭摄像头时采集；来电响铃期间不会打开麦克风或摄像头。通话内容不录制、不保存、不上传；本机诊断日志只记录通话阶段与结束原因，不含声音、画面、昵称或网络地址。通话中切到其他应用或锁屏时，应用以「通话中」常驻通知保持通话，聊天会话也保持到通话结束；视频画面会暂停，直到你回到应用。

STUN、加密中继与无云端聊天

开启「远程连接增强」时（默认开启，可在设置中关闭），应用会向公共 STUN 服务器（小米、哔哩哔哩、Cloudflare、Twilio、Google 提供的公开服务）发送不含任何内容的地址查询，以得知本机的公网地址；并连接公共 MQTT 中继（默认是 EMQX 与 HiveMQ 的公开服务，也可在设置中改为你自建的服务器），用于投递加密后的连接邀请，以及在两台手机无法直连时转发会话数据。默认中继只使用 TLS 连接，不会在 TLS 失败时自动降级为明文；自定义中继仍可使用明文连接，此时主题与收发时机也会对网络路径可见，设置页会给出提示。投递前在本机加密，聊天内容另有端到端加密；STUN 服务器与中继能看到的只有你的 IP 地址、连接时间、随机主题名和密文大小，看不到消息、昵称、好友关系或公钥。好友会在已验证会话中各自提供随机数，协商独立的中继信箱秘密；仅凭双方公钥无法推导协商后的主题与密钥。尚未完成协商的旧好友或不支持协商的旧版本对端仍使用由双方长期公钥派生的兼容秘密，持有这些公钥的人可推导该旧秘密。连接建立、码作废或离开页面后，应用会请求撤除暂存在中继上的加密邀请；未能交给某家中继的撤回或作废会登记为待处理，并在该中继重连或下次启动后补发，启动时也会清理本机旧发件主题。实际清除时机仍取决于公共中继是否可用。本应用不使用 TURN；没有账号、推送服务或自有的消息、信令服务器，不做使用统计、行为分析或广告追踪，也不提供云存储。关闭增强后，远程连接仅在双方设备之间直接尝试建立，不访问上述任何服务器（即不使用 STUN/TURN 与中继）；受 NAT、防火墙、系统网络限制等影响，host 候选并不保证一定连接成功。应用包含 WebRTC 等第三方组件，其完整许可可在「关于」页阅读。

好友与防重放记录

可信好友会保存在本机应用私有 SQLite 数据库，包括好友 friendId、SPKI 公钥、显示昵称、稳定会话 ID、动态 endpoint 地址、旧设备关联（legacy link）、最近一次远程验证成功时间（lastRemoteSuccess），以及好友中继信箱的当前秘密与升级中暂存的秘密。地址变化时可能保留旧地址别名，以避免同一好友被拆成多个会话。邀请摘要和到期时间也会在本机保存，用于识别重放并拒绝已使用或过期的邀请。普通聊天消息不写入这些数据库。好友迁移快照仅用于本机存储维护，不是云备份。

普通消息与留存授权

普通文本、图片和表情包消息不建立持久发件箱，聊天进行中明文只活在会话内存中。单聊结束时按「谁发的谁做主」处理：你发的消息你自己可以保留查看；对方发的消息只有对方授权后你才能保留。有人主动结束对话时，连接保持，双方在聊天区各自选择允许对方查看全部、部分或不允许；你也可以选择自己不保留。保留的记录以密文存入本机保险箱，在好友主页确认本人后查看。聊天意外断联时，你还有 30 秒看完对方发的内容，之后对方发的文字会用对方设备的托管公钥加密保存在你的手机里，你自己无法解开；下一次和对方聊天时，对方会看到「上次意外断联，请确定是否允许他人查看」，对方放行哪些，你才能解开哪些，对方不允许或 7 天内没有表态即销毁；意外断联时对方发的图片不托管，直接焚毁。应用退到后台按意外断联处理。广播会话仍按原有倒计时处置。保险箱里已有的旧留存仍按原有 NFC 碰一碰或扫码授权规则解锁。

设备身份

在你同意本政策后，应用会在本机生成随机旧设备编号及长期身份密钥，保存在应用私有存储或系统密钥库中。配对、蓝牙连接和远程邀请会向对方提供用于识别与验证的标识、公钥或证明；对方可据此识别再次连接的本机。私钥不会作为好友公钥或邀请内容发送。卸载或清除应用数据会删除本机身份记录，但无法撤回已经交给对方的副本。

权限用途

蓝牙（附近的设备）用于与身边设备直连；定位（仅 Android 11 及以下）是系统扫描旧式蓝牙设备的要求，本应用不读取、不记录位置；相机仅在拍照发送、制作表情、扫码或视频通话时使用；麦克风仅在语音 / 视频通话进行中使用；NFC 仅用于碰一碰配对与留存/解锁授权确认；通知仅用于后台连接保持与新消息提醒；存储权限（仅旧系统）仅在导出图片到相册时使用；振动仅用于配对、焚毁等动作的触觉反馈；前台服务仅在连接或等待期间、以及通话期间以常驻通知保持连接或通话；生物识别仅用于保险箱本机解锁等本人确认。权限可在系统设置中关闭，对应功能可能因此不可用。

内容规则与溯源标记

默认双人锁模式下，已留存内容每次查看仍需对方按既有方式授权解锁；对方可撤回授权。若你打开「本机直接查看」，本机会保存查看所需钥匙副本，之后无需对方在场；撤回不影响已保存副本。本应用页面背景及你导出到系统相册的图片会嵌入不可见溯源标记，内容是你的昵称（开发者模式下为开发者姓名）和时间，用于外泄后追溯来源。标记不包含设备标识或位置信息；重绘、翻拍或打印扫描后可能无法恢复。

加密说明

碰一碰、扫码与手动蓝牙配对建立的会话使用端到端加密；手动连接会显示安全码，请与对方口头核对。远程邀请使用长期身份签名和临时会话密钥；复制邀请的外部渠道不参与本应用的密钥托管。

本机日志与诊断

应用会在本机私有目录留存三类排障信息，不自动上传：①最近一次崩溃堆栈（供你复制给开发者）；②焚毁审计（只记录消息编号与结果）；③连接诊断报告（设备型号、Android 版本、蓝牙/NFC/权限状态、对端昵称与脱敏地址）。只有你主动复制或导出时，这些信息才离开应用，接收者由你决定。

开发者模式

隐藏的开发者模式仅供开发者及授权测试人员排障，需要在「关于」页连点版本号并导入开发者签发密钥。开启后可提供本机日志查看、抓包台，以及部分页面的「允许截图」开关；抓包台只含本应用自身的帧类型、长度、消息编号、序号、对端蓝牙地址与本机资源请求，不记录任何消息正文、图片或页面内容；聊天、图片查看、处置、保险箱等显示对方内容的页面仍始终防截屏。记录默认只在本机内存中，不自动上传，只有主动导出时才保存为本机文件。悬浮小窗需要「显示在其他应用上层」权限，拒绝后使用应用内页面。开发者密钥与开启状态加密保存在本机，退出或到期时清除相关密钥与记录。

保险箱

保险箱内容加密存放于本机应用私有目录，其安全性依赖设备锁屏、系统密钥库与生物识别能力，请妥善保管设备。

撤回同意

你可以在设置的「关于」中撤回同意：应用会清除本机全部数据（含设备身份、好友与邀请记录、保险箱、审计日志）并退出。你已保存到相册、复制到剪贴板或经外部渠道分享的文件、邀请和信息不在应用控制范围内，需要你自行删除或联系接收者处理。

防破解保护

正式版会在本机检测本应用是否正被调试器附着，或被 Frida、Xposed 等工具注入。一经确认，为防止你的数据被借本应用自身解密，应用会自动、不可恢复地销毁本机全部密钥与本地数据（含设备身份、好友与邀请记录、保险箱、授权记录、诊断日志）并退出；下次启动会提示发生了什么，之后等同全新安装，好友需要重新添加。检测只在本机进行，不上传任何信息；设备已 root 本身不会触发销毁。

边界声明

本应用无法防止对方用另一台设备拍屏，也无法控制外部渠道或接收者如何保存你主动提供的信息；在已 root 或被改动过的设备上，系统安全机制可能失效，请谨慎使用。
